# 📚 SAL — مساعد المكتبة الذكي (Smart Library Assistant)

> **SAL** هو مساعد مكتبة ذكي وتفاعلي يعمل بالكامل داخل متصفح المستخدم دون الحاجة للاتصال بخادم خارجي لعمليات الذكاء الاصطناعي (Local/In-Browser AI)، مصمم لمساعدة الطلاب والباحثين في الوصول السريع والذكي للكتب والمراجع داخل المكتبات الجامعية.

---

## ✨ الميزات الرئيسية (Key Features)

* **🧠 بحث معنوي ذكي (Semantic Search):** استخدام نموذج ذكاء اصطناعي متعدد اللغات (`paraphrase-multilingual-MiniLM-L12-v2`) لاستخراج المتجهات (Embeddings) وفهم قصد المستخدم وحالته النفسية/الاهتمام دون الاعتماد الفعلي على الكلمات المفتاحية فقط.
* **🌐 يعمل 100% داخل المتصفح (Client-Side AI):** يعتمد على مكتبة `@huggingface/transformers` للتشغيل المباشر داخل المتصفح لضمان السرعة والخصوصية واستمرارية العمل offline بعد التحميل الأول.
* **⚡ إكمال تلقائي تكيفي (Adaptive Autocomplete):** نظام بحث نصي سريعة واقتراحات فورية أثناء الكتابة.
* **🗺️ خريطة مكتبة تفاعلية 2D (Interactive 2D Map):** رسم تفاعلي لطوابق المكتبة وأرففها باستخدام HTML5 Canvas مع إمكانية تحريك شخصية افتراضية بالأسهم أو النقر للوصول المباشر إلى الرف المطلوب.
* **🏛️ تخصيص الكليات (Faculty Personalization):** واجهة لاختيار الكلية وتفضيل مراجع وتخصصات معينة (طب، هندسة، علوم حاسب، إلخ).
* **🧾 وصل استعارة حراري (Thermal Receipt Modal):** توليد طباعة فورية لوصل الاستعلام يوضح موقع الكتاب والرف ورقم التصنيف مع إمكانية الطباعة.
* **📌 نظام حجز الكتب (Hold Request System):** إمكانية طلب حجز الكتب غير المتاحة (المستعارة) وحفظ الطلبات سحابياً/محلياً (`localStorage`).
* **📊 بطاقات بيانية (Infographics Support):** عرض بطاقات وسائط توضيحية وملخصات بصرية للكتب مع إمكانية التكبير (Lightbox).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** HTML5, CSS3 (Modern Dark Theme), JavaScript (ES6+ Modules)
* **AI & Machine Learning:** Transformers.js (`@huggingface/transformers`)
* **Graphics & Mapping:** HTML5 Canvas API (2D Engine)
* **Standard Compatibility:** تم تصميم هيكل بيانات الكتب لتوافق مع معايير **MARC21 / UNIMARC** ونظام **Koha** لإدارة المكتبات.
